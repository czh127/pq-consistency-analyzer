# pq‑consistency‑analyzer
PQ产品一致性检测分析工具

> 基于 Python + Tkinter 实现的工况数据分析GUI工具，读取CSV测试数据，完成滤波、PQ曲线绘制、迟滞回环计算、产品加权一致性评估，自动输出图片图表与完整Excel检测报告。

## ✨ 功能特性
- 📂 读取多份 CSV 测试原始数据，支持自定义列索引、文件编码
- 🧮 滑动窗口滤波处理原始压差数据
- 📈 自动生成各类分析图表
  - 单产品性能PQ图
  - 全部产品PQ总对比图
  - 迟滞回环分析图
  - 产品一致性分析图、压差平均值图
  - 去程 / 回程 / 去回程合并PQ图表
- ⚖️ **加权一致性影响分析**，定位影响一致性的产品，给出缩放调节建议
- 📊 自动生成完整Excel报告：原始数据表、迟滞数据表、一致性对比、加权影响分析，Excel内嵌散点图表
- 🖼️ 内置图片预览器：滚轮缩放、拖拽平移、双击复位，LRU缓存避免内存泄漏
- ⏯️ 运行时支持**暂停 / 恢复 / 停止**分析任务，线程安全，暂停无CPU空转
- ⚙️ 大量可视化配置项，图表样式、图例开关、流量电流参数均可在界面调整
- ✂️ 图例文件名简化：支持4种文件名裁剪模式，优化图例显示效果

## 📋 环境依赖
Python版本：`Python >=3.9`

安装全部依赖：
```bash
pip install numpy pandas matplotlib openpyxl pillow
```

| 库 | 版本要求 | 作用 |
|---|---|---|
| numpy | >=1.21 | 数值计算 |
| pandas | >=1.3 | CSV数据解析处理 |
| matplotlib | >=3.5 | 绘图生成图表 |
| openpyxl | >=3.0 | Excel报告读写、内嵌图表 |
| pillow(PIL) | >=9.0 | 图片预览模块图像处理 |

> Tkinter 一般随Python自带；部分Linux系统需要手动安装：
> Ubuntu/Debian：`sudo apt install python3-tk`

## 🚀 运行方式
### 方式1：直接运行源码
1. 将主程序 `pq_analyzer.py` 放到你的**CSV测试数据文件所在文件夹**
2. 打开终端，进入该目录，执行：
```bash
python pq_analyzer.py
```
3. GUI窗口弹出，确认「工作目录」为csv数据所在目录
4. 修改各项分析参数（默认参数可直接用于测试）
5. 点击 `🚀 运行分析` 开始处理

> ⚠️ 注意：程序会扫描当前工作目录下全部 `.csv` 文件作为输入数据。

### 方式2：打包为exe（Windows免Python环境运行）
使用 `pyinstaller` 打包：
```bash
pip install pyinstaller
pyinstaller -w -F pq_analyzer.py
```
- `-w`：关闭黑色控制台窗口
- `-F`：打包成单个exe文件
> 打包完成后exe输出在 `dist` 文件夹。将exe复制到csv数据同级目录双击运行。

## ⚙️ 重要配置简要说明
1. **CSV数据列索引**：配置电流、流量、压差所在列，从0开始计数
2. **REF_FLOW**：标准参考流量点，逗号分隔
3. **CONSISTENCY_MODE 一致性模式**
   - `0`：(最大值+最小值)/2 对称均值
   - `1`：全部文件真实平均值【推荐】
   - `2`：以指定基准文件作为均值计算一致性
4. **LEGEND_KEYWORD & LEGEND_MODE**：图例文件名裁剪
   - mode `0` 删除识别文字以及前面内容
   - mode `1` 仅删除识别文字前面内容，保留关键字
   - mode `2` 删除识别文字以及后面内容
   - mode `3` 仅删除识别文字后面内容，保留关键字

## ⚠️ 注意事项
1. CSV文件编码，Windows导出csv常用 `gbk`，如读取报错可切换为 `utf‑8`
2. 单文件不要超过内存上限，超大csv建议预处理分片
3. 运行过程不要移动、删除CSV源文件以及输出文件夹
4. 图片预览仅支持png/jpg/bmp等常规图片格式
5. 程序内部使用线程执行分析，请勿重复多次点击运行按钮
