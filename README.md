# pq-consistency-analyzer

PQ 产品一致性检测分析工具

> 基于 Python + Tkinter 实现的工况数据分析 GUI 工具，读取 CSV 测试数据，完成滤波、PQ 曲线绘制、迟滞回环计算、产品加权一致性评估，自动输出图片图表与完整 Excel 检测报告。

---

## ✨ 功能特性

- 📂 读取多份 CSV 测试原始数据，支持自定义列索引、文件编码
- 🧮 滑动窗口滤波处理原始压差数据（按电流分组滤波）
- 📈 自动生成各类分析图表
  - 单产品性能 PQ 图
  - 全部产品 PQ 总对比图
  - 迟滞回环分析图
  - 产品一致性分析图、压差平均值图
  - 去程 / 回程 / 去回程合并 PQ 图表
- ⚖️ **加权一致性影响分析**，定位影响一致性的产品，给出缩放调节建议
- 📊 自动生成完整 Excel 报告：原始数据表、迟滞数据表、一致性对比、加权影响分析，Excel 内嵌散点图表
- 🖼️ 内置图片预览器：滚轮缩放、拖拽平移、双击复位，LRU 缓存避免内存泄漏
- ⏯️ 运行时支持**暂停 / 恢复 / 停止**分析任务，线程安全，暂停无 CPU 空转
- ⚙️ 大量可视化配置项，图表样式、图例开关、流量电流参数均可在界面调整
- ✂️ 图例文件名简化：支持 4 种文件名裁剪模式，优化图例显示效果
- 📁 自定义工作目录选择，支持切换不同数据集文件夹

## 📋 环境依赖

- **Python 版本**：>= 3.9
- **操作系统**：Windows / macOS / Linux

### 安装依赖

```bash
pip install -r requirements.txt
```

### 依赖清单

| 库 | 最低版本 | 用途 |
|-----|---------|------|
| pandas | >= 1.3.0 | CSV 数据读取与处理 |
| numpy | >= 1.21.0 | 数值计算与滤波 |
| matplotlib | >= 3.5.0 | PQ 曲线、迟滞图、一致性图绘制 |
| openpyxl | >= 3.0.0 | Excel 检测报告生成（含内嵌散点图） |
| pillow | >= 9.0.0 | GUI 图片查看器（缩放/平移/预览） |

> **注意**：`tkinter` 为 Python 标准库，无需 pip 安装。
> 部分 Linux 系统如缺失可执行：`sudo apt install python3-tk`

## 🚀 运行方式

### 方式 1：直接运行源码

1. 将主程序 `pq_analyzer.py` 和 `requirements.txt` 放到任意目录
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 运行程序：
   ```bash
   python pq_analyzer.py
   ```
4. GUI 窗口弹出后，点击「选择目录」指定 CSV 测试数据所在文件夹
5. 修改各项分析参数（默认参数可直接用于测试）
6. 点击 `🚀 运行分析` 开始处理

> ⚠️ 程序会扫描指定工作目录下全部 `.csv` 文件作为输入数据。

### 方式 2：打包为 exe（Windows 免 Python 环境运行）

使用 `pyinstaller` 打包：

```bash
pip install pyinstaller
pyinstaller -w -F pq_analyzer.py
```

- `-w`：关闭黑色控制台窗口
- `-F`：打包成单个 exe 文件

> 打包完成后 exe 输出在 `dist` 文件夹。将 exe 复制到任意目录，运行后选择 CSV 数据文件夹即可。

## ⚙️ 重要配置简要说明

1. **CSV 数据列索引**：配置电流、流量、压差所在列，从 0 开始计数
2. **REF_FLOW**：标准参考流量点，逗号分隔
3. **CONSISTENCY_MODE 一致性模式**
   - `0`：(最大值+最小值)/2 对称均值
   - `1`：全部文件真实平均值【推荐】
   - `2`：以指定基准文件作为均值计算一致性
4. **LEGEND_KEYWORD & LEGEND_MODE**：图例文件名裁剪
   - mode `0` 删除识别文字以及前面内容
   - mode `1` 仅删除识别文字前面内容，保留关键字
   - mode `2` 删除识别文字以及后面内容
   - mode `3` 仅删除识别文字后面内容，保留关键字

## ⚠️ 注意事项

1. CSV 文件编码，Windows 导出 csv 常用 `gbk`，如读取报错可切换为 `utf-8`
2. 单文件不要超过内存上限，超大 csv 建议预处理分片
3. 运行过程不要移动、删除 CSV 源文件以及输出文件夹
4. 图片预览仅支持 png/jpg/bmp 等常规图片格式
5. 程序内部使用线程执行分析，请勿重复多次点击运行按钮
